# AI Overseas Sales Engine V1

自动化海外B2B客户开发系统底座。

## V1目标
- 客户采集与补全
- 去重与黑名单
- 0-100 AI评分 / A-B-C-D 分级
- CRM生命周期管理
- 个性化首封开发信
- 队列化发送、限速、失败重试
- 回复分类
- 3/7/14/30天自动跟进
- 高意向客户人工接管

## 当前已完成
- TypeScript/Fastify API骨架
- PostgreSQL/Prisma数据模型
- 客户评分服务
- 健康检查接口
- 环境变量与发送限速配置

## 安全原则
1. 所有外联必须经过队列和限速。
2. 拒绝/退订客户写入黑名单后不得再次自动联系。
3. 客户来源、评分原因和发送结果必须可追溯。
4. 不使用绕过平台限制的非官方批量操作。
